# Contributions / Mitarbeit

## Deutsch

TMC Practice wird von [Nimcoz](https://github.com/Nimcoz) betreut.
**Mitarbeit am offiziellen Projekt nur nach vorheriger Absprache.**

- Bitte zuerst ein [Issue](https://github.com/Nimcoz/TMC-Practice/issues) mit
  deinem Vorschlag eroeffnen und auf die ausdrueckliche Zustimmung von Nimcoz
  warten, bevor du mit einem fuer dieses Projekt vorgesehenen Beitrag beginnst
  oder einen Pull Request einreichst.
- Nicht abgesprochene Pull Requests werden nicht angenommen und koennen ohne
  weitere Pruefung geschlossen werden.
- Eine Absprache gibt keine Schreibrechte und garantiert keine Uebernahme.
  Nimcoz entscheidet, welche Aenderungen in das offizielle Projekt kommen.
- Fehlerberichte und Fragen sind ohne vorherige Absprache willkommen.
  Bitte keine ROMs, privaten Spielstaende oder Zugangsdaten hochladen.

Das Repository bleibt oeffentlich. Diese Beitragsregel verhindert nicht die
von GitHub vorgesehenen Ansichts- und Fork-Funktionen; ein Fork ist eine eigene
Kopie und aendert dieses Repository nicht. Die Regel ist keine neue Lizenz und
aendert keine bestehenden Rechte. Siehe [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## English

TMC Practice is maintained by [Nimcoz](https://github.com/Nimcoz).
**Contributions to the official project require prior agreement.**

- First open an [issue](https://github.com/Nimcoz/TMC-Practice/issues) describing
  your proposal and wait for explicit approval from Nimcoz before starting work
  intended for inclusion in this project or submitting a pull request.
- Unagreed pull requests are not accepted and may be closed without review.
- Agreement does not grant write access or guarantee acceptance. Nimcoz decides
  which changes are included in the official project.
- Bug reports and questions are welcome without prior agreement.
  Do not upload ROMs, private saves or credentials.

The repository remains public. This contribution policy does not prevent
GitHub's viewing and forking features; a fork is a separate copy and does not
change this repository. This policy is not a new license and does not alter
existing rights. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
