# TMC Practice — 日本語ガイド

[English](README_EN.md) · [Deutsch](README_DE.md) · [Français](README_FR.md) · [Español](README_ES.md) · [Italiano](README_IT.md) · [日本語](README_JA.md)

TMC Practice は『**ゼルダの伝説 ふしぎのぼうし**』に練習・探索用メニューを追加する改造パッチです。
**v1.0.0** には USA 版・欧州版・日本版それぞれ専用の BPS パッチがあります。
翻訳されているのはこのガイドです。**Practice メニュー自体の表示は英語のままです。**
欧州版の言語選択と日本版のゲーム内テキストは維持されます。
ゲーム内で見つけやすいよう、以下のメニュー名は英語表記をそのまま使用しています。

## 1. ダウンロードと導入

1. [TMC Practice v1.0.0](https://github.com/Nimcoz/TMC-Practice/releases/tag/v1.0.0) を開きます。
2. このガイドの言語ではなく、**元の ROM の地域**に合うパッチを 1 つだけダウンロードします。
   - USA 版：`TMC-Practice-v1.0.0-USA.bps`。
   - 欧州版（英語・フランス語・ドイツ語・スペイン語・イタリア語）：`TMC-Practice-v1.0.0-Europe.bps`。
   - 日本版：`TMC-Practice-v1.0.0-Japan.bps`。
3. 通常のゲーム内セーブデータを別の場所にコピーしてバックアップします。
4. BPS 対応のパッチ適用ツールで、**未改変の元の ROM** に BPS パッチを適用します。
5. 出力された `.gba` をエミュレーターで開き、同じ地域の通常セーブデータを使います。
6. **L + R + Select** でメニューを開閉します。保存済みの独自キー設定がある場合は、そちらが優先されます。

対応する ROM の正確なハッシュ値は [ROM 互換性一覧](ROM_COMPATIBILITY.md) を参照してください。
元の ROM のチェックサムエラーを無視しないでください。パッチの重ね掛け、外部 AR コードや
別の Practice／No-Clip 改造との併用、旧ビルドのエミュレーター・ステートセーブの読み込みは避けてください。
ROM、セーブデータ、ステートセーブは同梱していません。地域間のセーブ変換ツールも配布していません。

## 2. 操作と設定

- **十字キー：** 行を選択します。左右で編集可能な値を変更します。
- **A：** 実行・決定。**B：** 戻る・キャンセル。
- **破壊的な操作：** 画面の確認表示に従います。通常は確認行で **L + R** を押したまま、もう一度 **A** を押します。
- **生の数値は 16 進数です。** 左右で 1 ずつ変更し、対応する 1 バイトの項目では L/R で `0x10` ずつ変更します。
- **SETTINGS：** テーマ、キー割り当て、永続的なメニュー設定を扱います。メニュー設定の保存は、未保存のゲーム進行を**自動保存しません**。

## 3. メニューの見方

| メニュー | 内容 |
| --- | --- |
| PRACTICE | 練習用タイマーと操作、ゲーム画面へのタイマー表示 |
| PLAYER / MOVEMENT | リンク、移動、No-Clip、カメラ |
| INVENTORY | アイテム、装備、ビン、各エレメント |
| WORLD / WARP | 部屋移動、お気に入り、導入・エンディングの再生 |
| FLAGS | ゲーム状態のフラグ確認・編集 |
| DEBUG | ゲーム画面へのデバッグ情報表示 |
| CHEATS | リソース関連、Enemy Freeze、Infinite Time などのチート |
| SETTINGS | 外観、操作、保存されたメニュー設定 |
| ACTORS / OBJECTS | アクター一覧、生データ指定の生成、停止、削除、テレポート |

収集状況、フラグ、確認後に実行する **100%** 操作は、ストーリー進行を変更する場合があります。
試す前にバックアップを取ってください。未使用／Beta の項目は、復元されたベータ版コンテンツではありません。

## 4. 通常プレイ以外でメニューを開く

ゲーム本来のインベントリ画面、会話・カットシーン、タイトル・導入、エンディング画面に対応します。
ゲーム世界を破壊的に変更する操作には通常プレイ状態が必要で、これらの画面では無効になる場合があります。
フェード、リソース転送、実際の EEPROM セーブ書き込み中はメニューが待機します。
画面遷移のすべてのフレームを中断できるわけではありません。

## 5. 導入やエンディングを再生する

通常プレイ中に **WORLD / WARP → STORY INTRO** または **ENDING / CREDITS** を選びます。
**A** を押し、確認のためもう一度 **A** を押します。会話中、カットシーン中、
ゲーム本来のインベントリ画面からは再生を開始しないでください。

**RETURN FROM REPLAY** は再生を終了し、元の部屋を読み込み直します。
ゲーム本来のセーブ領域 1,204 バイト全体を RAM に退避し、帰還時に復元します。
部屋の一時的なアクターまでは、エミュレーターのステートセーブのようには復元しません。
再生中は他の変更操作、チート、計時を一時停止します。エンディングの再生は通常のセーブ確認前に戻ります。
通常のストーリークリア時のセーブ処理は変更しません。
エミュレーターをリセットすると、RAM 上の一時的な帰還ポイントは失われます。

## 6. アクターツール

**ACTORS / OBJECTS → RAW NATIVE SPAWNER** では、ゲーム本来のカテゴリ・名前と
kind/ID/type/type2/timer/subtimer/flags/parent/layer の生の値を指定できます。
**QUICK SPAWN PRESETS** は生データ指定モードを制限しません。部屋・階層・バリエーションの
厳選された許可リストはありませんが、対応するゲーム内処理がない場合やアクター用領域が満杯の場合は生成を拒否します。
546 個のネイティブスロットと 118 種類の地面アイテムに名称があり、未特定の 25 項目は意図的に **UNKNOWN** としています。

**ROOM ACTOR LIST** からアクターを選び、停止・削除・位置変更ができます。
**LINK TO ACTOR** はリンクをアクターへ、**ACTOR TO LINK** はアクターをリンクへ移動します。
現在の部屋内での移動であり、別の部屋へのワープは行いません。
共通の XYZ 構造を持たないマネージャーは **NO GENERIC XYZ** と表示され、汎用の位置変更は使えませんが、停止・削除は可能です。
アクター自身の AI が位置を戻してしまう場合は、先に停止させてください。

2 人目のリンク、不適切なボスやタイプ、必要な部屋・スクリプト・親アクターがない組み合わせは、
クラッシュや進行不能の原因になります。ボスを削除しても**倒した扱いにはなりません**。
問題が起きたら、必要に応じてセーブせずに読み込み直してください。

## 7. Enemy Freeze・Break Free・Infinite Time

- **Enemy Freeze：** ボスと、当たり判定を持たない表示用の体のパーツも停止対象です。別カテゴリの飛び道具は個別に停止する必要がある場合があります。
- **Break Free：** ゲーム本来の終了処理を通して表示中のテキストを閉じ、プレイヤーの操作を解放します。実行済みのストーリースクリプトは取り消しません。後続のスクリプトにより再び操作が制限される場合があります。
- **Infinite Time：** アンジュのコッコ集め、闇ハイラル城のカウントダウン、目の形のスイッチの時限起動、すでに有効なお守り・幸運の薬の持続時間が対象です。すべてのタイマー、アニメーション、カットシーンを停止する機能ではありません。カウントダウンの結果判定・報酬処理や時限効果の終了を進めるには、無効にしてください。
