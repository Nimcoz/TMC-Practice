# Changelog

## 1.0.1 — No-Clip hardware fix and lava walking

- Relocate the unchanged No-Clip payload out of the ROM expansion area that
  returned incorrect data on the tested EZ-Flash Omega Definitive Edition.
- Allow walking over lava floors with No-Clip enabled; disabling No-Clip
  restores the original lava reaction. This is not general invincibility.
- Rebuild and verify the USA, Europe and Japan BPS patches and source package.
- Add focused lava, controller-toggle and actor-iterator regression coverage.

## 1.0.0 — first public package

- Promote the tested USA SCENES and EU/JP builds unchanged.
- Include all existing Practice features and separate BPS downloads.
- Add public English/German documentation and sanitized verification.
